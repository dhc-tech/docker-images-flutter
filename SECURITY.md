# Security Policy

## Supported Versions

Currently, the `main` branch and the latest published Docker tags are supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to [security@dhc.tech](mailto:security@dhc.tech) or securely report it via [GitHub Security Advisories](https://github.com/dhc-tech/docker-images-flutter/security/advisories/new).

All security vulnerabilities will be promptly addressed.
